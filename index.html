About DHCP

DHCP (Dynamic Host Configuration Protocol) automatically gives devices an IP address and related settings (mask, gateway, DNS) when they join a network. This avoids manual configuration and prevents duplicate addresses.

DORA: Discover (client broadcasts), Offer (server proposes an address), Request (client asks for it), Acknowledge (server confirms the lease).

Ports: DHCP servers listen on UDP port 67; DHCP clients use UDP port 68.

Lease: an address is loaned for a set time. The client must renew it before it expires or give it up.

This page is a JavaScript model of DHCP. It never changes your computer's real network settings.
